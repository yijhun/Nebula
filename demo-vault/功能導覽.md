# 歡迎使用 Nebula

這一頁串起 Nebula 主要功能。**並排模式**（⌘2）左邊編輯、右邊即時預覽；
按工具列 🔨 或 ⌘E 可以編成 PDF。逐段看下去就會用了。

## 1. 數學

行內公式 $E = mc^2$、$v_{\rm LSR} = -17.7\ \mathrm{km\,s^{-1}}$。
打 `\` 會跳自動補全（含 `\msun`→`M_\odot`、`\kms`、`\vlsr` 等天文別名）。

區塊公式：

$$
T(r) = T_0 \left(\frac{r}{r_0}\right)^{-q}, \qquad
\dot{M} = 4\pi r^2 \rho\, v_r
$$

## 2. 引用

用 Zotero（⌘⇧K）或 arXiv/ADS（⋯ ▸ 找文獻）插入引用：MRI 見 [@balbus1991]，
落塵模型 [@ulrich1976]。點引用可在 Zotero 開啟；編譯時自動產生 references.bib。

## 5. 圖表（草稿速覽）

```chart
type: scatter
log: xy
xlabel: $\nu$ (Hz)
ylabel: $F_\nu$
param: a = 3e-23 [1e-24, 1e-22]
plot: model = a * x^0.9
fit: powerlaw
x, flux, flux_err
1e11, 2.1e-12, 4e-13
1e12, 8.5e-12, 1.2e-12
1e13, 3.2e-11, 5e-12
```

滑過圖按 ✎ 開**互動編輯器**（拖 `a` 滑桿看曲線動、選擇擬合）。
數據多時可改用 `data: obs.csv`（放進 vault）。轉 LaTeX 時 chart 會自動變成 pgfplots 正式圖。

## 6. 幾何示意圖（圖解編輯器）

插入選單 ▸ 圖表 ▸ 圖解編輯器：點選畫點、箭頭、圓、角度、矩形、多邊形、
雲氣團，以及 3D 座標軸/球/立方體，輸出成可再編輯的 TikZ。下面是一個範例：


（開「即時 PDF 預覽」或編譯後可見真正的 TikZ 渲染。）
