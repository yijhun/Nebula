# 歡迎使用 Nebula

這一頁串起 Nebula 主要功能。**並排模式**（⌘2）左邊編輯、右邊即時預覽；
按工具列 🔨 或 ⌘E 可以編成 PDF。逐段看下去就會用了。

## 1. 數學

行內公式 $E = mc^2$、$v_{\rm LSR} = -17.7\ \mathrm{km\,s^{-1}}$。
打 `\` 會跳自動補全（含 `\msun`→`M_\odot`、`\kms`、`\vlsr` 等天文別名）。

區塊公式：

$$
T(r) = T_0 \left(\frac{r}{r_0}\right)^{-q}, \qquad
\dot{M} = 4\pi r^2 \rho\, v_r
$$

## 2. 引用

用 Zotero（⌘⇧K）或 arXiv/ADS（⋯ ▸ 找文獻）插入引用：MRI 見 [@balbus1991]，
落塵模型 [@ulrich1976]。點引用可在 Zotero 開啟；編譯時自動產生 references.bib。

## 7. 會算數的筆記

行內反引號 `= 3*(4+2)` 會直接顯示答案；`= 1.38e-23*300` 這種數量級估算最好用。
`calc` 區塊可以帶變數，逐行累積：

```calc
# 自由落體 1 秒
g = 9.81
t = 1
s = 0.5*g*t^2
```

支援 `+ − × ÷ ^`、`sin cos tan exp ln log10 sqrt abs` 等函數、`pi`/`e`、科學記號。

## 8. 圖形跟 Keynote 互通

- **拖進來**：從 Keynote（或瀏覽器）直接拖圖形/投影片進編輯器 → 自動存 vault、插 `![[圖]]`。
- **貼進來**：Keynote ⌘C → 筆記 ⌘V（或 ⇧⌘V「貼上為圖片」強制貼圖）。
- **拖出去**：滑過 chart/圖解/3D 圖，按住 **⠿** 拖進 Keynote → 高解析 PNG。
- **向量輸出**：按 **⧉ PDF** → tectonic 編譯成無限縮放的向量 PDF 放上剪貼簿，投影不糊。

## 9. 錄演講 → 會議筆記

⋯ ▸ 錄演講/轉文字：可先填**主題**（本地 AI 會自動生成該場術語表，讓 Whisper 更準）。
錄音時面板縮成右下角小條，**可以繼續寫筆記**。轉錄完成後填講者/場合 → 自動套會議模板：
摘要走「防幻覺」三段式（Key points / To verify / Suspected transcription errors）——
聽不懂的詞會標 `[?原文]` 而不是腦補，人名、引用、數字全部進「待人工確認」。

## 10. 文獻工作流

- ⋯ ▸ 找文獻：搜 **arXiv / ADS / Zotero 書庫**，一鍵匯入＝references.bib + 文獻筆記 + 插引用；
  ADS 還能看引用網路（references / citations）。
- 筆記庫（論文分頁）：狀態篩選（待讀/讀中/讀完）、**從 Zotero 回填書目**（只填空白欄位）、
  開 Zotero 條目 / **開 PDF 附件**。
- PDF 閱讀器：螢光標記 → 建文獻筆記；**擷取圖**模式框選論文圖 → 存 PNG＋向量 PDF、
  嵌入語法自動複製（含 `[@citekey]` 出處）。

## 11. 待辦與會議追蹤

- ⋯ ▸ 我的待辦：全 vault 未完成 `- [ ]` 依筆記分組，勾了就寫回原檔；
  「彙整到 Daily Note」一鍵整理（也會**每週自動**彙整一次，設定可關）。
- 筆記庫（會議分頁）：同一場合的歷次會議串成**時間軸**。

## 12. 與 Claude Code 共筆

⋯ ▸ **用 Claude Code 開啟 vault**：在終端機開 Claude Code、工作目錄就是這個 vault
（第一次會自動放一份 CLAUDE.md 說明筆記慣例）。Claude 改了筆記，
開著的編輯器會**自動重新載入**——外部編輯、git pull、iCloud 同步也一樣。

## 13. 投稿

寫成專案後：資料夾右鍵 ▸ 投稿前檢查（缺標題/摘要/引用/圖），再 ▸ 投稿打包
（攤平 .tex + 只含引用的 .bib + 所有圖，打包成 zip）。模板可選 ApJ / MNRAS / A&A。
